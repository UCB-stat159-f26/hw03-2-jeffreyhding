Question:
Should the pyproject.toml file be done towards the start of creating a Python package or near the end?

Response:
It should be done toward the start, after you've established the basic package name/layout but before you've developed much functionality.

The reason is that pyproject.toml isn't final cleanup or documentation. It defines how the package is built and installed, along with core package metadata and dependencies. Having it early means we can install tenniscareer in editable mode while developing it and continuously verify that we're actually building an installable package—the exact thing HW03 will ultimately grade by installing directly from GitHub.
